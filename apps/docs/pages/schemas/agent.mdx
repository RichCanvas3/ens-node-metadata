# Agent

AI agent identity metadata aligned with ERC-8004 registration format.

| type | string | - | Registration file type discriminator | - |
| display-name | string | Y | Display name for the agent (distinct from ENS path) | - |
| description | string | - | Natural-language description of the agent | - |
| services | string | - | Advertised service endpoints | - |
| x402-support | boolean | - | Whether x402 payment flow is supported | - |
